<overview>
## Problema
O painel Smart Core Assistant possui inconsistências graves de layout e funcionalidades quebradas:
1. Templates de tenants não seguem o Design System unificado "Smart Core" (Gold/Stone)
2. Erro visual no dashboard acima do botão "Sair"
3. Gestão de usuários (/tenants/users/) não funciona - botões de convite e permissões quebrados
4. Configuração de IA (/tenants/config/ai/) com campos não editáveis para usuários de tenant

## Usuários Alvo
- Owners de tenants que precisam gerenciar suas configurações e equipe
- Funcionários de tenants que acessam o painel
- Administradores do sistema

## Métricas de Sucesso
- Todas as páginas internas usam o mesmo Design System (base_dashboard.html)
- Formulários de convite e permissões funcionam corretamente
- Campos de configuração de IA são editáveis para usuários autorizados
- Sem erros visuais no dashboard
</overview>

<functional-decomposition>
## Árvore de Capacidades

### Capacidade: Unificação do Design System
Garantir que todas as páginas internas sigam o padrão Smart Core (Gold #a98f71, Stone backgrounds)

#### Feature: Migrar templates de usuários
- **Descrição**: Alterar templates users/list.html, users/invite.html para usar base_dashboard.html
- **Entradas**: Templates atuais usando admin/base_site.html
- **Saídas**: Templates usando base_dashboard.html com classes Tailwind
- **Comportamento**: Substituir classes Bootstrap por classes Tailwind do Design System

#### Feature: Migrar templates de configuração
- **Descrição**: Alterar templates config_ai.html, config_database.html, config_evolution.html, config_trello.html, config_debug.html, dashboard.html para usar base_dashboard.html
- **Entradas**: Templates atuais usando base_tenants.html
- **Saídas**: Templates usando base_dashboard.html com classes Tailwind
- **Comportamento**: Substituir variáveis CSS customizadas por classes Tailwind

#### Feature: Corrigir erro visual no dashboard
- **Descrição**: Identificar e corrigir elemento quebrado acima do botão "Sair"
- **Entradas**: Layout atual com erro
- **Saídas**: Layout corrigido sem erros visuais
- **Comportamento**: Inspecionar HTML/CSS e corrigir problema

### Capacidade: Correção de Funcionalidades
Garantir que formulários e botões funcionem corretamente

#### Feature: Corrigir URLs nos templates
- **Descrição**: Substituir URLs incorretas (tenant_users:list -> tenants:user_list)
- **Entradas**: URLs antigas/incorretas
- **Saídas**: URLs corretas usando namespace tenants:*
- **Comportamento**: Buscar e substituir referências de URL

#### Feature: Verificar permissões de edição IA
- **Descrição**: Garantir que campos em config_ai são editáveis para usuários autorizados
- **Entradas**: Formulário atual não editável
- **Saídas**: Formulário editável para owners e admins
- **Comportamento**: Verificar views e templates, corrigir lógica de permissão
</functional-decomposition>

<test-strategy>
## Estratégia de Testes

### Gestão de Usuários
**Caminho feliz**:
- Acessar /tenants/users/, clicar em "Convidar", preencher formulário, enviar
- Esperado: Convite criado, mensagem de sucesso, redirecionamento para lista

**Casos de borda**:
- Tentar convidar email já existente
- Esperado: Mensagem de erro "Email já cadastrado"

**Casos de erro**:
- Acessar /tenants/users/ sem estar logado
- Esperado: Redirecionamento para login

### Configuração de IA
**Caminho feliz**:
- Logar como owner, acessar /tenants/config/ai/, editar campos, salvar
- Esperado: Dados salvos, mensagem de sucesso

**Casos de borda**:
- Enviar JSON inválido no campo entity_types_json
- Esperado: Erro de validação "JSON inválido"

**Casos de erro**:
- Funcionário sem permissão tenta editar
- Esperado: Campos readonly ou mensagem de acesso negado
</test-strategy>
