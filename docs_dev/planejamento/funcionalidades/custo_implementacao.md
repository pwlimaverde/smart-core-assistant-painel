# Proposta de Custos de Implementação (Cliente: Ecoprint)

Abaixo detalhamos os custos estimados para a infraestrutura, operação e manutenção contínua do sistema.

### 1. Infraestrutura (Responsabilidade do Cliente)
Para garantir total controle e propriedade dos dados, a infraestrutura de banco de dados e API de conexão (Evolution API) será hospedada em servidor contratado diretamente pelo cliente.

*   **Item:** Hospedagem VPS (Banco de Dados + Evolution API)
*   **Sugestão:** Plano KVM2 da Hostinger
*   **Custo Estimado:** **R$ 467,88 / ano**

### 2. Hospedagem do Sistema (Aplicação)
Custo referente à hospedagem da aplicação "Smart Core Assistant Painel" (Back-end e Front-end).

*   **Item:** Servidor de Aplicação
*   **Custo Estimado:** **R$ 467,88 / ano**

### 3. Custos Operacionais Variáveis (Inteligência Artificial)
O custo de operação da IA (LLM) é variável conforme o volume de mensagens trocadas.

*   **Estimativa de Uso:** Média de 2.000 mensagens/mês
*   **Custo Estimado:** **$10,00 USD (aprox. R$ 55,00) / mês**

### 4. Manutenção e Evolução
Valor referente ao suporte técnico, atualizações de segurança e desenvolvimento de melhorias contínuas no sistema.

*   **Item:** Taxa de Manutenção e Melhorias
*   **Custo Estimado:** **R$ 200,00 / mês**

| Categoria | Periodicidade | Valor Estimado (R$) |

### 5. Inclusos na Entrega
Além da infraestrutura e software, o projeto contempla a transferência de conhecimento necessária para o sucesso da operação:
*   **Sistema "Chave na Mão":** O cliente recebe o sistema 100% funcionando, configurado e testado.
*   **Treinamento Operacional:** Capacitação completa para os atendentes utilizarem o sistema no dia a dia.
*   **Treinamento de Gestão:** Treinamento específico para configuração e personalização dos agentes de IA e fluxos.
